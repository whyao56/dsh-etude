# 变更

## 0.4.0

0.3.0 把界面原样搬回来了，但界面里有一半的东西是「没有后端」的占位：四个评分键写
「未接调度」、统计页八张图写「暂时算不出来」、详情页调度写「没有调度记录」、「说」
这一面录音灰着、「改」这一面改写存不进去。0.4.0 把这些后端补上，从「看得见的壳」
变成「用了会留下东西」。

### 换了什么

- **复习调度**（`lib/review.js` + `factory/review.json`）：四档评分 1–4，ease 在
  1.3–2.8 之间挪，新卡首评排 1 分钟 / 3 天 / 8 天 / 15 天，重来 1 分钟，前三次
  封顶 15 天。记录是追加日志，最多留 5000 条。
- **学习页四个评分键**接上调度：每格写的是「点下去会排到什么时候」，点完按后端
  返回的真实间隔重写四格，220ms 高亮反馈，失败就写「评分没记上：…」。
- **统计页**：复习/保留率/间隔分布/逐小时/回答按钮/难度六张卡从「藏起来」变成真数；
  只有一次都没练过才写「还没读到复习记录」。
- **详情页**：调度、卡片信息、最近七次都用真记录，日期和面名按记录格式化。
- **录音**（`lib/record.js` + `media/record/`）：「说」这一面真能录、能回放、能重录，
  只认 webm/ogg/wav/mp3，单段 ≤ 8MB，同一句重录会删掉旧的。麦克风被拒、浏览器
  不支持、录出来太长，都只改那一行文案，不弹窗。
- **改写**（`lib/packs.js` 的 `saveVariant` + `example.vary`）：「改」这一面写完能存进
  账本，下次进来会回填；只留最后一次（改写是练习，不是修订历史）。
- 新增 RPC：`review.submit` / `review.stats` / `review.card` / `review.recent` /
  `example.record` / `example.record.bytes` / `example.record.delete` /
  `record.stats` / `example.vary`。`state` 里多了 `review` 摘要（到期数、练过几张）。

### 修掉的

- 例句没有 `id`，复习记录的键改用 `ord`（第几条），跟详情页的 `skin.ord` 是同一套。
- 卡片页右上角那句「Anki 已连」早就换成了「账本已连 · N 个包」，牌组下面还多一句
  「今天 N 张到期」。
- `.pip` 不再拿「有没有素材」冒充「练没练过」。

### 仍然是「没有」的（不假装）

- 音标、英文释义、词频：账本里没有这些字段。
- 生图、资源挂载、多语言（`LANGUAGES = ['en']`）。
- 挖句台：没有视频/字幕来源。
- 「改」这一面补语音：没有补语音的端点，按钮上如实写着。

## 0.3.0

0.2.0 把 15 页样式稿「翻译」成 React 重写，丢了很多东西：启动页没了、8 个页面根本没搬、
工厂页 12 个弹层被砍、设置页 4 组被砍、顶栏「插件」按钮点不开。翻译必然丢细节。
0.3.0 改成**原样搬**。

### 换了什么

- **界面就是 `design/` 那 15 页本体**，跑在一个 iframe 里。样式、交互、弹层、动效、
  启动页的星空，全部来自设计稿自己的脚本，插件不再翻译任何一页。
- **构建多了一步**：`node scripts/inline-design.cjs` 把 15 页的 body 抽出来，公共
  CSS/JS 各存一份（`build/pages.json`，实测 css 332KB + js 94KB + body 1.5MB）；
  `node scripts/build-client.cjs` 内联进 `client.js`（1.8MB）。
- **每页一个数据适配器** `src/adapters/<page>.js`：把设计稿里写死的演示数字换成账本
  里的真数字。契约见 [ADAPTERS.md](ADAPTERS.md)。
- **导航走消息桥**：页面里的 `./study.html?w=x` 在构建时改写成 `#nav:study?w=x`，
  点击时 postMessage 给宿主切页，iframe 里不会真的去导航（没有服务器）。
- 旧的五页 React 分片（`src/40-cards.js` 等）改名成 `.js.off` 留着做参考，不参与构建。

### 修掉的

- 顶栏「插件」菜单能点开了：它本来就是设计稿的 `<details>`，0.2.0 把它换成了没有
  onClick 的静态按钮。
- 启动页回来了，星空 canvas 完整（内联后 403KB 的自包含页）。
- 工厂页 12 个弹层、设置页 11 组、句库/详情/我的/教程/听说读写改 8 个页面全部回来。

### 仍然是「没有」的（不假装）

- 录音（说这一面）、生图、资源挂载、多语言（`LANGUAGES = ['en']`）、复习历史与调度
  （没有 reviews / due / interval / ease / retention）。这些位置如实标注，不编数字。

## 0.2.0

界面整套换掉，底下那套（造料 / 挑图 / 语音 / 打包 / 导出）一行没动。

### 换了什么

- **侧栏「卡片工厂」点进去是设计稿那一套界面了**：深色底、主色 `#97B1F0`、
  五面练习（听/说/读/写/改）、状态只用「齐了 / 差 N 个 / 还没开始」三种说法。
  0.1.0 的通用灰底 + 大图列表没有了。
- **界面有了源文件**。以前 `client.js` 是手写的 2755 行单文件；现在是 `src/` 下
  九个小分片 + `scripts/build-client.cjs` 拼出来。改界面改分片，改样式改
  `design/app.css`，都跑一遍 `node scripts/build-client.cjs`。
- **界面跑在 shadow root 里**，样式和宿主互不干扰；`design/app.css` 在构建时
  被改写成 `:host` 形态。

### 多语言

- `lib/packs.js` 的 `LANGUAGES` 是唯一开关（现在是 `['en']`）。加一门语言要动：
  `LANGUAGES`、`lib/prompts.js` 的语言相关段落、`lib/tts.js` 的音色映射、
  界面 `src/99-register.js` 里的 `LOCALE`。**现在只支持英文，不是假装支持。**
- 包的 `language` 一路带到契约 v2 的清单里（`lib/manifest.js:53`），导出时按包的
  语言写，不写死 `en`。

### 修掉的

- 卡片页的列从「未学习 / 学习中 / 待复习」（Anki 的调度口径）换成
  「例句 / 配图 / 语音 / 到哪一步」—— 插件没有调度引擎，画不存在的数比空着更糟。
- 统计页不再画复习历史（插件没有历史）。凡是算不出来的都写成「还没有」。
- 构建产物漏了 `return module.exports` 导致 `apply` 是 undefined（面板整个不挂）。
- `apply()` 里调 `useState`（不是组件）导致 hook 报错；改成惰性取连接。

### 没做的（写在这里，免得以为做了）

- 三态（空 / 加载中 / 出错）的 CSS 在设计稿里齐了，但只有卡片页真的接上了，
  其余页还在搬。
- 学习页的评分键还不算下次复习时间 —— 调度引擎没做。
- 设置页只放插件真有的设置，设计稿里 11 个分组砍掉的那几个是插件没有的能力。
