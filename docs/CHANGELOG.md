# 变更

## 0.2.0

界面整套换掉，底下那套（造料 / 挑图 / 语音 / 打包 / 导出）一行没动。

### 换了什么

- **侧栏「卡片工厂」点进去是设计稿那一套界面了**：深色底、主色 `#97B1F0`、
  五面练习（听/说/读/写/改）、状态只用「齐了 / 差 N 个 / 还没开始」三种说法。
  0.1.0 的通用灰底 + 大图列表没有了。
- **界面有了源文件**。以前 `client.js` 是手写的 2755 行单文件；现在是 `src/` 下
  九个小分片 + `scripts/build-client.cjs` 拼出来。改界面改分片，改样式改
  `design/app.css`，都跑一遍 `node scripts/build-client.cjs`。
- **界面跑在 shadow root 里**，样式和宿主互不干扰；`design/app.css` 在构建时
  被改写成 `:host` 形态。

### 多语言

- `lib/packs.js` 的 `LANGUAGES` 是唯一开关（现在是 `['en']`）。加一门语言要动：
  `LANGUAGES`、`lib/prompts.js` 的语言相关段落、`lib/tts.js` 的音色映射、
  界面 `src/99-register.js` 里的 `LOCALE`。**现在只支持英文，不是假装支持。**
- 包的 `language` 一路带到契约 v2 的清单里（`lib/manifest.js:53`），导出时按包的
  语言写，不写死 `en`。

### 修掉的

- 卡片页的列从「未学习 / 学习中 / 待复习」（Anki 的调度口径）换成
  「例句 / 配图 / 语音 / 到哪一步」—— 插件没有调度引擎，画不存在的数比空着更糟。
- 统计页不再画复习历史（插件没有历史）。凡是算不出来的都写成「还没有」。
- 构建产物漏了 `return module.exports` 导致 `apply` 是 undefined（面板整个不挂）。
- `apply()` 里调 `useState`（不是组件）导致 hook 报错；改成惰性取连接。

### 没做的（写在这里，免得以为做了）

- 三态（空 / 加载中 / 出错）的 CSS 在设计稿里齐了，但只有卡片页真的接上了，
  其余页还在搬。
- 学习页的评分键还不算下次复习时间 —— 调度引擎没做。
- 设置页只放插件真有的设置，设计稿里 11 个分组砍掉的那几个是插件没有的能力。
