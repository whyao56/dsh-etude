# 重建提示词 · dsh-etude（卡片工厂）

> 这份文件是给你（下一个接手的模型）看的作业单。用户会在新对话里把这份文件指给你，
> 你的任务是**从零把 `dsh-etude` 这个 DSH 插件重做一遍**，并且把前端做到比
> `design/` 里那套样式稿更好 —— 那套在用户眼里只有 60 分。

---

## 0. 一句话与边界

**给它一个词、一个固定说法或一整句，它造出一整套能练、能听、能看的语言卡片。**

边界（用户明确要求过，不要越界）：
- **不要引用、不要提及、不要依赖任何叫 Etude 的外部应用**。插件自己就是全套。
- 不装数据库、不起第二个服务、不要求用户打开别的软件。
- 一切都在插件内部闭环：造例句 → 搜图 → 预检 → 挑图 → 合成语音 → 试听 → 打包 → 校验 → 导出。

## 1. 三条不可破的规矩

这三条是产品底线，任何「为了顺一点」的改动都不许破：

1. **每张图必须有人点过头。** 搜候选 → 像素预检 → 九宫格让人挑一张 → 锁定。
   没有任何「自动配好了就入库」的路。
2. **语音必须真播过、人点过「我听过了」才算数。** 播放进度到六成才许点那个按钮。
   机器自动跑出来的包，复核人字段写 `auto:not-human`，并且**只能**用来看看效果，
   不能当成交付物。
3. **内容寻址 + 幂等键。** 同一个目标重复调用不重复花钱：
   `idempotencyKey({target,kind,language,examples,variants,model,promptVersion,voice})`
   命中就直接返回已有的那一份。

顺带一条：**失败要说清楚失败在哪一步**，不要吞异常返回 ok:false 了事。

## 3. 运行环境的技术事实（这些是踩出来的，别重新试）

### 3.1 插件形态
- 这是一个 DSH 插件，`package.json` 里 `name: dsh-etude`，入口 `index.js`。
- 工具用 `defineTool` 注册，**`output.schema` 是 Harness 自己的 value schema DSL**，
  必填属性上写 `required: true`；写 JSON-Schema 的 `required: [...]` 会报
  `JsonSchemaError: unsupported JSON schema: schema.required is not supported by the value schema DSL`。
- 客户端面板走 `window.__ModuleLoader__.load({ id, factory })`，照着同 profile 里
  `dsh-image-generation` 的写法抄 —— 它在这个运行时里是实装且跑着的，风险最低。
- 插件禁用/启用的重载方式：`plugin_manager` 先 `enabled:false` 再 `enabled:true`，
  一次 set 不会重新挂载。

### 3.2 数据放哪
- 插件自己的状态放 Host 侧：`%LOCALAPPDATA%\dsh-etude\`，主索引 `factory/library.json`。
  **不要**放 Config —— Config 是给用户拧的旋钮，不是给界面频繁读写的数据。
- 写 json 用「写 tmp 再 rename」，避免半截文件。
- 成品导出到 `Downloads/dsh-etude/<target>-<id>/`。导出前先清空目标目录，拷完再拿
  副本跑一遍 `validateManifest` 才算成功。

### 3.3 媒体怎么送到界面
宿主的 Web 界面整站要鉴权，`<img src>` / `<audio src>` 拿不到 token，所以：
**不要开 HTTP 路由**。用 loopback RPC 回 base64：
`connection.rpc.handle('/etude', handler, { authority: 'loopback' })`，
统一返回 `{ ok, value }` / `{ ok: false, error }`。

### 3.4 图片检索
- 两个源：Openverse + Wikimedia Commons。**Openverse 经常 504，Commons 稳定**；
  两个都试，先到的先用，失败要说清是哪一个挂了。
- Node 的 fetch **不读系统代理**。必须走 `lib/net.js` 里的 CONNECT 隧道
  （注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings` 读
  `ProxyServer`，本机常见 `127.0.0.1:7897`）。
- 像素预检用 sharp，两条判据：
  - 纯色/近纯色：`stdev < 6` → 丢
  - 渐变/渐变色块：**看二阶差分** `secondDiff < 1.1` → 丢（只看方差会把渐变放过）
- 同一批候选要去重（按 sha256），否则两条例句会挑到同一张照片。

### 3.5 语音
- 默认 Edge TTS：**纯 JS 实现**，`lib/edge-token.js` 做非标准 SHA-256 + cs64，
  已与 Python `edge_tts` 逐字节对齐（8/8）。WebSocket 用 profile 里的 `ws`，
  Node 原生 WebSocket **不能设 header**，所以必须用 `ws`。
- 文件名校验注意：语音文件名形如 `edge-<20hex>.mp3`，**不要**用「只认图片扩展名」
  的通用校验函数去校验它 —— 会被判非法，表现为播放键没声也不报错。
- 也支持接 OpenAI 兼容的 TTS，配置里留接口，默认不用。

### 3.6 卡片包契约
- `format: "card-pack"` **v2**。老值 `etude-lesson` 只能进 LEGACY_FORMATS 发 warning。
- 三份同源校验器，缺一不可：`contract/validate.js`（Node）、
  `contract/validate.py`（Python）、`contract/manifest.schema.json`。
- 打包前硬校验：缺图、缺人工复核、哈希不对 → 拒绝打包并**列出差哪些**。

## 4. 产品设计（这部分决定了它是不是一个好产品）

### 4.1 单词是索引，句子是核心
用户不是来背单词的，是来学会「这句话在什么场合说」。所以：
- 卡片以**句子**为单位，一个词只是一组句子的入口。
- 每条例句必须交代**场景**：谁在说、在哪、什么时候、说完会怎样。
  **不是翻译**。翻译只回答「这句什么意思」，场景回答「我什么时候能用」。
- 一个词下可以有多个**义项**（sense）。义项是结构单位：义项 N + 释义 +
  情境概率（生活 / 四六级 / 考研 / 雅思）+ 调音区 + 「再加一句」。
- 例句之间要**真的不一样**：场景互不相同，中文说法故意不一致。

### 4.2 一句话五个面：听 / 说 / 读 / 写 / 改
每个面都写清楚「输入 → 输出」，界面上就这么标（很小的副文本）：

| 面 | 输入 → 输出 |
|---|---|
| 听 | 声音 → 画面 |
| 说 | 画面 → 声音 |
| 读 | 句子 → 画面 |
| 写 | 画面 → 拼写 |
| 改 | 换一个说法 |

学习页的六块内容（背景 / 图·资源 / 句子 / 声音 / 录音 / 打字）是**材料**，
五个面是**练法**。不要混在一起。

### 4.3 批量与搜索
- 批量造的分隔符**自动认**：换行、逗号、顿号、分号、斜杠、制表符混着粘都要认。
  不做「先选分隔符再粘」—— 粘贴是随手动作，先选一遍等于把成本摊在每一步。
- 全局搜索的排序：`log(1+打开次数) × e^(−距今天数/14)`（frecency）。
  log 防刷榜，14 天常数≈半衰期 10 天。
  命中分：开头 100 / 词首 80 / 中间 60，压过常用度。
  **砍掉模糊子序列匹配** —— 输入 `stat` 会命中 "succumbed to temptation"，害人。
- 中文界面要能用英文搜：每条加 `en` 别名拼进同一个 haystack。

### 4.4 动效原则
- **只在该动的地方动**：滚动到「整块看得见」（可见比 ≥ 0.92）才演示；
  用户已经看过的不重播；往上滑回去的不重播。
- 动画是「我以为它本来就是这样的」那种程度，不是表演。
  时长参考：位移/淡入 180–260ms，展开 380–520ms，大图重绘 600–900ms。
- 不要用 CSS 简写 `animation` 去叠门控 —— 简写会把没写的
  `animation-play-state` 重置成 `running`，写在它前面的 `paused` 等于没写。

## 5. 前端要做到什么程度（这是 60 分和 100 分的分界）

### 5.1 硬性视觉规格
- **节奏网格**：间距只用 4 的倍数（4/8/12/16/20/24/32/48）。不要出现 7px、13px、17px。
- **一套色相系统**：
  - 一个主色（蓝紫系）+ 一个警告/失败色（红）+ 一组中性阶（4–6 级）。
  - 装饰性颜色只能出现在 **2px 以下**的元素上：小圆点、竖条、细线。
  - **禁止**把六种不同色相做成满宽的横条或色块去分区。教训见 7.1。
- **字阶只有 5 级**：11 / 12.5 / 15 / 20 / 28。不要更多。
  正文对比度：主文字 `.92`、次文字 `.6`、提示 `.38`，**收起的/未激活的用 `.38`**。
- **对齐**：任何一列文字的左缘必须彼此对齐；同一行内不同块的尺寸不一致时，
  用等宽数字（`font-variant-numeric: tabular-nums`）把数字列对齐。
- **圆角只有三档**：6（小组件）/ 14（卡片）/ 999（胶囊）。不要每处都不同。

### 5.2 每个页面必须做到
- 有空态、加载态、错误态，**三种都要画出来**，不能只做「有数据」的那一种。
- 键盘可达：Tab 顺序合理、焦点环可见、Esc 关弹层、`Ctrl/Cmd+K` 全局搜索。
- 尊重 `prefers-reduced-motion`：全部动画降级为立即完成。
- 1440 宽、1024 宽、900 宽三个断点都要**截图检查过**。
  900 宽的常见崩法：两栏挤成一窄条、句子一列一个词、悬浮按钮压住正文。

### 5.3 动效与页面切换
- 页面之间**不许白闪**。做法：跳转前铺一层与底色同色的全屏遮罩、
  opacity 0→1（约 460ms，`cubic-bezier(.4,0,.85,.55)`），落地页在 `<head>` 里
  （**首次绘制之前**）就把同色遮罩铺成 `opacity:1`，然后等 `DOMContentLoaded` + 两帧
  再淡到 0。这一段写不对就会闪一帧白。
- 启动页 → 主页面的过渡要**像一个连续的镜头**：遮罩盖上的同时，背景动画还在动，
  不要出现「一张静态图被盖住」的观感。

### 5.4 性能红线
- 一帧内的 `stroke()` 次数、`fill()` 次数、DOM 写入次数都是成本。
  同一颜色的线**合并成一条 path 再 stroke 一次**（这条曾把一个 canvas 动画从
  每帧上千次 stroke 降到约 25 次）。
- 不要「降分辨率再放大」当优化 —— 全屏合成本身才是瓶颈，那样反而更慢。
- 长列表用虚拟滚动或分页；`will-change` 只在动画期间给，结束就撤。

## 7. 别重复这些错（都是真金白银踩出来的）

### 7.1 视觉
1. **六种颜色做成满宽横条分区** = 条纹灾难。颜色只做标记（≤2px 的点或竖条）。
2. **失败的三段式**：为省性能把一条线切成 2–3 段、每段一个固定透明度 → 同一条线上
   出现三道硬边。要渐变就一次画完一条弧。
3. 原生 `<select>` 的弹出层由操作系统画，CSS 改不到 —— 要么自绘，要么接受它丑。
4. `.page` 上有 `transform`，会劫持里面所有 `position:fixed`（弹层、拖拽、搜索面板）。
   对策：这些层 `document.body.appendChild(el)` 挂到 body 上。
5. `[hidden]` 会被 `display:flex` 盖掉，需要 `.xxx[hidden]{display:none!important}`。
6. SVG 元素上的 CSS `transform` 会顶掉 `transform="rotate(...)"` 属性。
7. `stroke-dasharray: 1000` 是**用户单位不是百分比**，长路径会断尾 —— 用
   `pathLength="1"` 归一化。
8. `rect` 的 `rx` 会把四个角都磨圆；只想圆上面两个角就手写 path。
9. 环图/饼图的 `fill` 会被容器类（`.c1…c6`）盖过元素上的 `fill="none"` → 整张饼填实。
10. 同一行元素如果同时写了 `left` 和 `right`，宽度会被拉满 —— 想靠右就 `left:auto`。

### 7.2 动画
11. CSS 里的 `animation` 简写会重置 `animation-play-state`，门控必须 `!important`。
12. `WeakSet` 只有 `has`，写 `done.get(el)` 抛 TypeError；异常发生在 IO 回调里，
    表现是「滑到底全空白」，`node --check` 查不出来。改完动画一定跑一次带
    `window.onerror` 的探针页。
13. 星空/长曝光类动画：角速度必须**与半径无关**（同一角速度），否则整片像旋涡排水；
    拖影长度再按半径自然拉开，才像照片。
14. 淡入拖影要**按亮度排序**渐次加入，否则前 0.3 秒会「一批一批冒东西」，
    帧率没掉但看着卡。
15. `dt` 的抖动不要直接喂给转速，先平滑一层再算。
16. 想验证重动画只能靠「画够 N 帧就 `return 0` 停掉 rAF」再截图，软件渲染跑不动实时。

### 7.3 工程
17. 模板字符串会吃掉反斜杠：`'I\'m'` 生成出 `'I'm'` → 整页 SyntaxError。用 `&#39;`。
18. ESM 文件里没有 `require`，`require('node:fs')` 直接 ReferenceError。
19. 静态资源要带版本号（`?v=<app.css 的 mtime>`），否则用户永远看到旧 CSS。
20. 改代码要改生成器（`gen.mjs`），不要改生成物。
21. PowerShell 5.1 默认 GB2312，读写 UTF-8 文件必须显式 `-Encoding UTF8`，
    否则你会以为文件坏了（其实只是显示乱码，文件是好的）。
22. 对象字面量里引用还没定义的变量（`{ gain: 1 - Math.min(1, p) }`）会让整页黑屏。
23. 「降分辨率再合成」不是 canvas 性能优化，是负优化。

## 9. 工作方式

1. 先把 `design/` 跑起来、把 `design/DESIGN.md` 读完，**再写第一行代码**。
2. 每做一个页面，先出 2–3 个不同密度/排版的版本截图对比，选一个再往下做。
   不要第一版就定稿。
3. 每完成一个阶段就写进 `design/DESIGN.md`：为什么这么改、踩了什么、数字是多少。
4. 不确定的地方**问用户**，不要自己发明产品决策。
5. 交付前把 6.1 全跑一遍，把 6.2 逐条走一遍，截图贴进 `docs/GUIDE.md`。
