# 样式稿（design）

这是「卡片工厂」的**产品形态原型**，不是插件本体。纯静态 HTML + CSS + 一点原生 JS，
双击任何一个 `.html` 就能在浏览器里跑：不用起服务、不用装依赖。

## 一句话结构

```
system.css        设计系统：令牌 + 外壳 + 组件 + 分页样式（只这一份 CSS）
ui.js             交互：开关、自绘下拉、五面切换、图表入场、音频进度、方格转场、星轨
gen.mjs           生成器：扫 gen/pages/*.mjs，写出 15 页 + 每页 2–3 个变体
gen/ui.mjs        组件层：icon / btn / card / photo / chart / shell / states …
gen/data.mjs      演示数据：12 条句子、7 个词、7 个牌组、30 天预测、182 格热力
gen/pages/*.mjs   一页一个模块，导出 { meta, build(v) }
tools/shot.mjs    截图：node tools/shot.mjs cards 1440 900
tools/montage.mjs 联络表：把几张截图拼一张看
tools/photos.mjs  演示照片：裁掉生成器水印 → 4:3 → 1200×900
assets/photos/    七张演示照片（港口 / 办公室 / 咖啡馆 / 阅览室 / 夜街 / 地铁 / 晚饭）
```

## 十五页

```
index.html     开场页：星轨 + 一句主张 + 一个按钮
cards.html     卡组：今天该练什么、牌组树、待办
factory.html   工厂：词当索引，句子当核心；五维度 / 图 / 声 / 变体 / 资源
study.html     学习：一屏一张，五个面（听 / 说 / 读 / 写 / 改）
listen.html    听：只有声音          read.html   读：只有句子
speak.html     说：只有图和录音      type.html   写：拼图和原声
vary.html      改：换一个说法
library.html   句库：所有句子，按「缺图/缺声/没试听」筛
detail.html    一句的四份素材
mine.html      挖句：粘一段文字，挑含目标词的句子
stats.html     统计：今天 / 未来 / 记忆 / 分布
settings.html  设置：十一个分区，一次看一块
tutorial.html  教程：三分钟走完产线
```

## 为什么有这个目录

插件本体（`../`）解决「怎么把卡片造出来」；这里解决「造出来之后长什么样、怎么练」。

核心只有一条：**单词是索引，句子才是核心**。一句话有五个面 —— 听（声音→画面）、
说（画面→声音）、读（句子→画面）、写（画面→拼写）、改（换一个说法），
每个面都写死「进来什么、出去什么」。所以卡片不是「一个词一张」，
而是「一句一张，五个面共用同一张图和同一条语音」。

每一面先只给一样东西，其余收起来：

| 面 | 直接给 | 说明 |
| --- | --- | --- |
| 听 | 只有声音（波形 / 时长 / 再放一遍） | 念得出来再翻 |
| 说 | 只有图 | 对着图讲，录音回放 |
| 读 | 只有句子 | 先想画面，翻开才有图 |
| 写 | 图 + 中文 | 拼出来，逐字符给反馈 |
| 改 | 句子 + 改写区 | 换一个说法，同一件事不许变 |

灰掉的不代表禁掉 —— 只是这一面不鼓励先看。

## 改样式稿的规矩

`gen/pages/*.mjs` 是**唯一真源**。直接改 `.html`，下次生成就没了。

```bash
cd design
node gen.mjs                       # 15 页 + 变体
node tools/shot.mjs cards 1440 900 # 截图到 _shots/
```

变体写在 `v/<name>-v<n>.html`，`v/index.html` 是版本对比索引；定稿版本才放到根目录。

`DESIGN.md` 是这一轮的设计流水：目标、验收尺子、每页三版的对比与定稿理由、
踩过的坑（现象 → 根因 → 修法）、三档宽度实测。
