# 样式稿（design）

这是「卡片工厂」的**产品形态原型**，不是插件本体。纯静态 HTML + CSS + 一点原生 JS，双击任何一个 `.html` 就能在浏览器里跑，不需要起服务、不需要装依赖。

打开顺序建议：

```
index.html     开场页（只是过场）
cards.html     卡片页：牌组表 + 接着练。点「测试牌组」那一行，或点 abandon / succumb，进学习页
study.html     学习页：一屏一张，五个面（听 / 说 / 读 / 写 / 改）
factory.html   工厂：单词当索引，句子当核心，点一句展开五维度 / 图 / 声 / 变体 / 资源 / 背景
library.html   句库：所有句子，按进度筛
stats.html     统计
settings.html  全局设置
```

## 为什么有这个目录

插件本体（`../`）解决的是「怎么把卡片造出来」；这里解决的是「造出来之后长什么样、怎么练」。

核心想法只有一条：**单词是索引，句子才是核心**。一句话有五个面 —— 听（声音→画面）、说（画面→声音）、读（句子→画面）、写（画面→拼写）、改（换一个说法），每个面都写死「进来什么、出去什么」。所以卡片不是「一个词一张」，而是「一句一张，五个面共用同一张图和同一条语音」。

## 学习页的规矩

每一面先只给一样东西，其余藏进右栏「还藏着什么」，点开照样能看：

| 面 | 直接给 | 背景按钮 | 写框 |
|---|---|---|---|
| 听 | 只有声音（波形 / 时长 / 再放一遍） | 灰，可点 | 灰，可写 |
| 说 | 只有图 + 资源链接 | 灰，可点 | 灰，可写 |
| 读 | 只有句子 | **高亮** | 灰，可写 |
| 写 | 只有图 + 资源链接 | **高亮** | **高亮，必须写** |
| 改 | 句子（目标词划线）+ 图 + 改写区 | 高亮 | 收起来 |

灰掉的不代表禁掉 —— 只是这一面不鼓励先看。

## 改样式稿的规矩

`gen.mjs` 是**唯一真源**。所有页面都由 `node gen.mjs` 生成，直接改 `.html` 下次生成就没了。

```
node gen.mjs        # 写出 15 个页面
```

改之前备份一下 `gen.mjs`（这个目录没有 git 以外的保护，仓库里也只留最终版）。

`DESIGN.md` 是这几十轮的设计流水：每一轮为什么改、怎么改的、踩了什么坑都在里面，包括被推翻的方案（例如「点进卡片页就直接开始练」被否掉，改成学习页单独一页）。
