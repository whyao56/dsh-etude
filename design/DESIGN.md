# 卡片工厂 · 设计流水（v2 重生）

> 这一版是「重做」，不是「改改」。目标写在最前面，然后是每一段做了什么、为什么、
> 踩了什么坑、实测数字是多少。所有截图都在 `design/_shots/`。

## 0. 目标与验收尺子

**要什么**：给一个词/固定说法/整句，造出一整套能练、能听、能看的语言卡片。
界面要让人一眼看懂「现在该做什么」，而不是一堆面板。

**这一轮的四条硬要求**（用户给的）：

1. 每张图必须人点过头、每条语音人试听过、幂等键不重复花钱 —— 三条底线不许破。
2. 不引用任何叫 Etude 的外部应用，插件自己就是全套。
3. 前端从 60 分做到 85 分以上，每个页面先出 2–3 个版本对比再定稿。
4. 1440 / 1024 / 900 三个宽度都要截图检查。

**量的尺子**（来自 docs/REBUILD.md 5.1，逐条对）：

- 间距只用 4 的倍数；字阶只有 11 / 12.5 / 15 / 20 / 28；圆角只有 6 / 14 / 999。
- 一套色相：1 主色 + 1 失败红 + 4–6 级中性。装饰色只能出现在 2px 以下元素。
  禁止六种色相做满宽横条分区。
- 正文对比度：主 .92 / 次 .6 / 提示 .38。
- 每页三态：空态、加载态、错误态。
- 键盘可达（Tab 顺序、焦点环、Esc 关浮层、⌘/Ctrl+K 搜索）。
- `prefers-reduced-motion` 下立即呈现终态（不是隐藏内容）。
- 1440 / 1024 / 900 三档都不崩：两栏不挤成窄条、句子不缩成一列词、悬浮按钮不压正文。

## 1. 怎么跑

```bash
cd design
node gen.mjs                 # 从 gen/pages/*.mjs 生成 15 页 + 15×3 个变体
node tools/shot.mjs cards 1440 900    # 单页截图 → design/_shots/cards-1440.png
node tools/montage.mjs _shots/sheet.png _shots/a.png _shots/b.png   # 联络表
```

- **唯一真源**是 `gen/pages/*.mjs`。改页面 = 改模块 + `node gen.mjs`，绝不手改 html。
- `gen/ui.mjs` 是组件层（图标、按钮、卡片、图表、壳），`gen/data.mjs` 是演示数据。
- 变体写在 `design/v/<name>-v<n>.html`，`design/v/index.html` 是版本对比索引。
- 截图机用 Chrome `--headless=new --screenshot`，不需要 CDP、不需要 seed。

## 2. 旧稿诊断（60 分的证据）

一页一页截出来看，问题不是「不好看」，是结构性的：

| 现象 | 证据（旧稿 1440 截图） | 根因 |
| --- | --- | --- |
| 页面像漂浮的岛 | 内容只占中间 980px，四周大片空 | 没有栅格，`.page` 没有侧栏对位 |
| 顶栏四组控件打架 | 左「插件」、中 tab、右搜索+齿轮、右上「动画·开」 | 调试药丸没删；tab 用 margin 居中，左右不等宽就偏 |
| 竖向死区 | cards 内容只到 y≈400；stats 每张卡里空 200px | 卡片高度靠内容撑，没有节奏 |
| 颜色当面积用 | study 评分条四块满宽红/琥珀/蓝/绿 | 用色相区分状态，而不是用字重和位置 |
| 数字三种强调色 | 卡组表「新/学/到期」蓝橙绿 | 同上 |
| 右栏参差 | 虚线按钮宽窄不一，右缘数字乱 | 没有 `tabular-nums`，宽度靠内容 |
| 空态是 11px 小字 | 空包时只有一行注释 | 空态没有当成一屏来设计 |

结论：**不是换配色能救的，要换骨架。** 于是整份重写：删掉旧的 `app.css`（190KB）、
17 个 `*.js`、旧的 15 个 html，改成 4 个文件的一层：`system.css` + `ui.js` + `gen.mjs` + `gen/`。

## 3. 设计系统（system.css）

一套令牌，页面里只用名字，不写死颜色。

```
面  --c-bg #0a0d13 / --c-bg-2 #0d1119 / --c-surf #131923 / --c-surf-2 #19212c / --c-inset #0c1017
线  --c-line / -2 / -3      = 白 6.5% / 10.5% / 17%
字  --c-ink #e9edf4 / -2 #a6adbd / -3 #727a8b / -4 #4c5363
主  --c-accent #a7bdf6（深墨字 #0c1424）/ --c-accent-2 #7e9bec
败  --c-danger #e0918c     成 --c-ok #7fc6a4     待 --c-warn #dcb47c
角  --r-1 6 / --r-2 14 / --r-3 999
影  --sh-1..4 + --sh-in（凹陷）
动  --ease cubic-bezier(.22,.8,.24,1) / --t-fast 140ms / --t-mid 220ms
值   --side 236 / --pad 32 / --maxw 1180
```

**壳**：左侧栏 236（sticky 全高，四组导航：造卡 / 卡片 / 练习 / 观察）+ 顶栏 52（sticky，
面包屑 + 搜索 + 两个圆钮）+ `.page` 1180 居中。

**为什么改成左侧栏**：旧稿是「顶栏 tab 居中」，一页只能挂三个 tab，实际有 15 页，
剩下 12 页只能塞进「插件」下拉。侧栏一次能看到全部四个区，且不占纵向空间。

## 5. 修过的坑（现象 → 根因 → 修法）

1. **品牌名和副标题横挤在一起** → `.brand-txt` 只是 `min-width:0`，两个 span 是行内 →
   加 `display:flex;flex-direction:column`。
2. **卡片页脚出现一个 400px 大的图标，把表格撑成巨块** → 内联 `<svg>` 只有 viewBox，
   没有宽高时浏览器给 300×150 的默认尺寸 → `icon()` 输出 `width="1em" height="1em"`，
   让图标跟字号走；需要固定尺寸的地方再用 CSS 覆盖（CSS 优先于属性）。
3. **右栏热力图溢出卡片** → 26 周 × (11+3)px = 364px > 300px 栏宽 →
   `.heat{overflow:hidden}` + `.heat.sm i{9px}`，右栏只放 19 周（`HEAT.slice(-133)`）。
4. **变体页整页没样式（白底蓝图标）** → 变体写在 `design/v/`，相对路径 `./system.css`
   指向不存在的 `design/v/system.css` → 生成时 `setBase('../')` 写 `<base href="../">`；
   页面模块不用管，`shell()` 统一读。
5. **`seg(['积压','每日上限'],'积压')` 渲染出 `undefined undefined`** → seg 只认 `{v,t}` 对象 →
   改成两种都收。
6. **学习页整页上下空一半** → `.stage-card` 高度靠内容撑 → `.stage-main` 加
   `display:flex;flex-direction:column;justify-content:center`，外层 `min-height:calc(100vh - 160px)`，
   卡片 `flex:1`。
7. **波形只有 200px 宽** → `.wave` 没有 `width:100%`，`i` 的 `flex:1` 无从发挥。
8. **`.stage-q` 的目标词是一块半高色块**，在 30px 字下像荧光笔涂歪 →
   改成 `color:accent` + 2px 下划线（`inset 0 -2px 0 var(--c-accent-line)`）。
9. **九宫格里出现「候选 4」裂图** → 演示照片缺 `p-street / p-subway / p-dinner`，
   不是布局问题；补齐素材即可（生成器免费层 1 张/45 秒，只能慢慢补）。

## 6. 三条底线的界面表达

界面上不许出现「自动入库」的路，也不许让没试听的语音过。

- **图**：候选 → 体检 → 九宫格 → 有人点了才写进清单。详情页「换一张」会退回「没做完」，
  旧图留在候选池里（不是删掉）。
- **声**：播放进度到 60% 才允许点「我听过了」；没点就打包，`pack.pack` 直接拒绝并说第几条。
- **花钱**：同一个（词、类型、条数、模型、提示词版本、音色）第二次按「造料」不发请求，
  直接返回已有那份。界面上表现为「秒回」，不是「正在生成」。
- 机器批量跑出来的包，清单里写 `auto:not-human`，界面标「样例」，不算交付物。

## 7. 三档宽度实测（1440 / 1024 / 900）

每页 × 三档 = 45 张，全部过了一遍。记的是**改了什么**，不是「看着还行」。

**1440**：15 页都成立。左栏 236 常驻，`.page` 1180 居中，内容左右留白 0（贴着栅格）。
**1024**：左栏收成 64（只剩图标），`--pad` 26。以下是这一档真正崩过、已经修掉的：

| 崩法 | 现象 | 修法 |
| --- | --- | --- |
| detail 图片吃满屏 | 4:3 图在 960 宽下变成 720px 高，整页只剩一张图 | `@media (max-width:1100px)`：`.dt-hero` 单列 + 图高 300（960 以下 240） |
| factory 两栏挤成窄条 | 280 的左侧栏还在，右侧内容被压到 600 以下，九宫格往右溢出 | 把 `.g-1-3 / .g-2-1` 一起加进 ≤1100 的单列规则；再给 `.g > *,.col > *,.row > *` 补 `min-width:0` |
| 工厂进度条竖着断字 | 190px 里塞四个横排步骤，「例句」断成「例/句」 | 新增 `.steps.v` 竖版（步骤之间用 1px 竖线连） |
| 波形只有 200px 宽 | `.wave` 没有宽度，`i{flex:1}` 无从发挥 | `.wave{width:100%}` |
| 学习页下面空 200px | `.stage-main` 靠内容撑高，卡片被拉长后留下死区 | 内容居中 + 评分条上面加一条 2px 的「第 3/12 —— 还剩 9 张」进度条 |
| 分段控件断字 | 「单词」竖排成两行 | `.seg button{white-space:nowrap}` |

**900**：单列。补了三处：`set-nav / tut-toc` 变横排胶囊（分组标题藏掉）、`set-row` 单列、
`ratebar` 两列。工厂页在这一档最干净——词表整宽、步骤竖排、句子一条一行。
启动页在 900 下把四张照片的扇形压到 `bottom:62px` + `scale(.88)`（卡片 196→170），
既不贴到视口底、也不压住页脚那两行小字。

**还剩的两个小毛病**（记下来，不假装没有）：

1. 句库表的「场景」列在 900 下只剩 10 个字，语义信息被吃掉一半。要么改两行，要么点开看。
2. 详情页「四份素材」右侧的值在 1024 下会贴到边，`·` 分隔的两段偶尔换行。

## 9. 真面板换皮（client.js）

样式稿是规格，插件本体才是要交的东西。这一轮把新设计落到 `client.js`，做法是**只换壳、不动管道**：
RPC 端点、幂等键、包状态机、图与语音的人工复核一道没改，改的是 `styles` 和 `FactoryPanel` 的外框。

### 9.1 换掉的 500 行 styles

旧的 `styles` 是 64 个零散键，字号 13/14/15/16 混着用，圆角 8 和 16 混着用。新的一套：

- 先在文件里定义 `ink{a,b,c}` / `line{a,b}` / `surf{a,b,c}` / `accent` / `onAccent` / `soft` / `softLine` / `danger` / `radius{sm:6,md:14,pill:999}`，页面里只引用这些名字。
- **颜色全部走宿主 token**（`--dsw-alias-*`），所以浅色主题跟着变，不用另写一套 light 覆盖；只有「比宿主再淡一档」的地方用 `color-mix`。
- 字阶收成 11 / 12.5 / 15 / 20 / 28 五级；间距全是 4 的倍数；圆角只有 6 / 14 / 999。
- 装饰色只出现在 2px 以下：制卡流水线的五段用 `border-left: 2px` 说话，不铺底色。
- 旧键一个没少（含 `tab(on)` `dot(on)` `banner(kind)` `listItem(on)` 四个函数键），另补 `stage(state)`、`cell(picked)` 两个之前漏掉的函数键 —— 少一个就是运行时 `styles.stage is not a function`，整块白屏。

### 9.2 换了外框的 FactoryPanel

原来是「一行顶栏：图标 + 标题 + 数据目录 + 输入框 + 造包 + 刷新」。现在是：

```
page（max 1180 居中，padding 28/32/72）
├─ header
│  ├─ headText：eyebrow「卡片工厂」/ h1「制卡 or 学习」28px / 一行数据目录
│  └─ headerActions：输入框 + 造一个包 + 刷新
├─ tabs（胶囊：制卡 / 学习）
├─ jobBar（有任务时才出现）
└─ body：list 264（sticky，卡片底）+ detail（自适应，gap 16）
```

h1 跟着当前区变（制卡 / 学习），这样切标签时标题也跟着说人话。

### 9.3 三处必须亲手修的地方

1. `styles.card` 是**行**方向 flex（图左文右），`cardNarrow` 才是竖的。原来写成块级容器，结果是每张卡片的图都撑满整卡、一句话被挤到图下面去。
2. `styles.media` 要 `flex:0 0 42%` + `position:relative`：不写 42% 图就吃满整卡；不写 relative，图上那颗「换一张」的绝对定位按钮会跑到页面外。
3. h1 / p 默认带 margin，面板里没有全局 reset 时会把页头挤成两截 —— `title` `subtitle` `eyebrow` 三个样式都写了 `margin: 0`。

### 9.4 怎么在没有浏览器的情况下看它长什么样

宿主的 Web 界面要带 token 的地址才打得开，headless Chrome 直接访问 `127.0.0.1:7052` 只会得到一行
`dsh web authentication required`。所以加了 `tests/panel-preview.mjs`：

```bash
node tests/panel-preview.mjs      # 产物 design/_shots/panel-{factory,empty,error}.html
```

它用和 `tests/client-smoke.mjs` 同一套假 React 把组件树跑一遍，再把宿主标签序列化成 HTML 落盘，
双击就能看真面板。三个状态（有包 / 一个包也没有 / 宿主连不上）各一份。

写这个预览工具踩的两个坑都出在**序列化**上，跟面板无关，但会骗人：

- `style` 里的数字一律补 `px` → `lineHeight:1.7` 变成 `1.7px`，页头副标题被压成一条虚线。
  只有长度类属性才补 px，`fontWeight` `lineHeight` `flex` `opacity` 这些保持无单位。
- 属性白名单漏了 `src` → 11 个 `<img>` 全没有源，预览里只剩 alt 文字，会误判成布局塌了。

### 9.5 这一轮没做完的

  没有按样式稿重排。下一轮把这三块按 `detail.html` / `factory.html` 的结构重写。
