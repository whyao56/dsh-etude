# dsh-etude

**DeepSeek Harness 插件：语言卡片工厂。**

给它一个词、一个固定说法、一句英文，它负责把「卡片」做出来 ——
8 条不同场景的例句、每条例句一张对得上情境的实拍图、一条能听清语气的语音，
然后交给 [Etude](https://github.com/whyao56/Etude) 去练（五通道 + 间隔重复）。

> 现状：**立项阶段**（0.0.0 骨架）。这一份文档是立项交接书，
> 不是成品说明 —— 见 [docs/HANDOVER.md](docs/HANDOVER.md)。

## 为什么不是「在 Etude 里继续改」

Etude 0.1.1 里有两半：训练器（好）和卡片工厂（坏）。

- 训练器：五通道、SM-2 变体调度、卡片浏览器、进度统计、跟读评分、备份恢复 —— 331 个测试、41 项冒烟、22 项 e2e 全过。
- 卡片工厂：配图一次成型、没有候选、界面只显示哈希、试听按钮不试听、
  语速音量在部分引擎下静默失效 —— 用户的原话是「完全就不是人能看的」。

这两半的节奏完全不同：造卡是**一次性、贵、需要人看一眼**；练卡是**长期、便宜、天天跑**。
混在一个进程里，工厂的毛病会拖着训练器一起被骂；工厂想换模型/换图源/换音色要改半个后端。

所以切开：

| | 谁做 | 在哪 |
|---|---|---|
| 造卡（LLM 写句、找图/画图、TTS、人工挑图） | **dsh-etude**（本仓库） | DSH 插件 |
| 练卡（五通道、调度、统计、跟读） | Etude 0.1.1（冻结为参考实现） | 本地 exe / 源码 |

## 三条一开始就定死的规矩

1. **每张图都有人点过头。** 检索候选 → 预检 → 九宫格挑图 → 锁定。没有「自动配好就入库」这条路。
2. **试听必须真能播。** 任何「合成成功」都不许只回字节数。
3. **重复的目标不重复收费。** 内容寻址 + 幂等键，只补缺的那几张。

## 目录（拟）

```
plugin/      DSH 插件本体（工具注册、job 编排、进度上报）
factory/     卡片工厂：例句 → 配图候选 → 语音 → manifest
media/       检索、预检（尺寸/方差/文字检测）、许可与来源记账
contract/    卡片包 v2 的 schema 与校验器（Python + JS 双份，必须同源）
docs/        立项交接书、决策记录、包格式说明
tests/       契约定型测试（不测 UI，测产物）
```
